# 关于本路线

软件测试开发正在被 AI 重塑：用例可以让 AI 出初稿，脚本可以让 AI 帮忙写，但「判断测得够不够、质量有没有滑坡、问题出在哪一层」仍然需要人。这份路线整理了一条从零基础到测试开发工程师（SDET）的完整学习路径：既打牢传统测试开发的功底，也补上 AI 时代的两门新功课——用 AI 提效测试，以及评测 AI 应用本身。

## 适合谁

- **在校学生 / 应届毕业生**：准备走测试开发、自动化测试、质量工程方向，需要一条从零到能求职的完整路径
- **功能 / 业务测试工程师**：业务熟悉但编程薄弱，想补齐编程、自动化和工程化能力，转型测试开发
- **程序员 / 后端开发**：有开发基础，看好质量工程方向，想把求职面扩展到测开
- **在职测试工程师**：想突破性能测试、质量平台、精准测试等进阶能力，冲击更高岗位
- **想学 AI 测试的工程师**：想把 AI 真正用进测试工作，或切入 AI 应用评测新方向

# 底子篇：新手技术底子

> 这组文章回答一个问题：**功能测试每天要用的那些技术，到底是什么。**F12 里看到的一堆英文、bug 单里的"接口 500"、开发嘴里的"看下日志"——本分类把 HTTP、抓包、SQL、Linux、检查清单、造数这些"最八股"的底子一次讲透。读者是零基础新人和转行人群，每篇从"这是什么"讲起，配可运行的命令和报文。

**用法建议**：01~05 是一条主线（HTTP → 状态码 → 方法 → 登录态 → 接口测试），建议按序读；06~12 按需检索，装工具、写 SQL、查日志时再来翻。所有命令和 SQL 都可直接上手练。

# 缺陷篇：缺陷管理

> 测试的日常一半在找 bug，另一半在管 bug：单子怎么提才不被退回、严重程度和优先级为什么是两回事、复现不了的 bug 怎么办、一堆缺陷数字怎么看。这组十篇把 **bug 从出生到关单再到复盘**的完整一生讲透。每篇都有模板、表格和真实系统例子，看完明天就能用。

**用法建议**：急着上手先读第 03 篇（提单模板）和第 02 篇（状态流转），入职第一周最救命；其余按序通读，第 08~10 篇适合转正前后想往上走一步的时候细看。

# 流程篇：研发流程与测试流程

> 这组文章回答一个问题：**软件是怎么从一句话想法变成线上功能的，测试嵌在哪一步、每步干什么**。写给刚入行、只知道"等产品提测"的新人——看完你会知道提测之前发生了什么、提测之后要扛什么，以及测试为什么绝不是一个"等活儿"的岗位。

**用法建议**：从 01 顺着读到 13 是最完整的路径，正好是一条从需求到上线的流水线；赶时间就单看卡住你的那一环；13 是收官串联篇，把前 12 篇装进一个两周迭代逐日走一遍，读完前面再看它收获最大。

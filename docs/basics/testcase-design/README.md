# 用例篇：测试用例设计

> 这一组回答一个核心问题：**拿到需求之后，测试用例到底怎么来？** 前半段讲用例本身的规范——要素、写法、优先级、评审；后半段是七种设计方法（等价类、边界值、判定表、因果图、正交、场景、状态迁移）逐个拆开讲，每种都配真实系统的完整用例表。写给刚入行、正在"凭感觉点点点"和"照模板填格子"之间徘徊的你。

**用法建议**：先读 01~05 建立用例观，再按方法篇顺序通读一遍，最后拿 15、16 两篇的三大页面和经典思维题自测——能把这三页讲出一套方法组合，你这组就算出师了。

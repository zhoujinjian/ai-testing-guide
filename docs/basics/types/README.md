# 类型篇：测试类型大全

> 这组文章回答两个问题：**测试到底有多少种、每一种在干什么**。读者是刚入行、被行话轰炸得发懵的新人——开会听到"先冒烟再回归""这是黑盒层面的活""顺手做个兼容"，每个字都认识，连起来不知道在说什么。读完这 13 篇，这些句子对你就是大白话。

**用法建议**：先读 01 总览，把"阶段、方法、目的"三个维度的地图装进脑子，再按需跳读；05（冒烟 / Sanity / 回归）和 08（性能全家桶）是日常工作与面试的双高频，值得精读两遍。

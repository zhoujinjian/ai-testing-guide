## 工具页结构

每个工具独立一个页面，固定结构：**工具介绍 → 基本信息（官网 / 项目地址 / 协议）→ 工具配图**。开源工具附 GitHub 仓库地址（仓库与 star 数经实时核验，标注核验时间）；商业产品标注「闭源」。

## 收录标准

- 优先收录：官方文档、活跃维护的开源项目、口碑稳定的经典书
- 商业课程谨慎收录，需注明性质与适用人群
- 链接失效请提 Issue，我们定期清理

欢迎推荐资源，参见[贡献指南](/about/contributing.html)。

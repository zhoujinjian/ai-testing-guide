# 资源汇总（规划中）

这个目录用于沉淀测试开发方向的工具、书籍、课程与社区资源，与路线各章末尾的「推荐资源」配套：路线内资源按学习阶段组织，这里按资源类型横向汇总并持续维护。

## 规划分类

| 分类 | 内容 |
| --- | --- |
| tools.md | 测试工具清单：接口调试、自动化、压测、抓包、评测框架，含选型对比 |
| books.md | 书单：测试理论、自动化、性能、质量工程，按阶段标注 |
| courses.md | 课程与教程：免费优先，标注适用背景 |
| communities.md | 社区与信息源：技术博客、公众号、开源项目 |
| practice.md | 练手平台与靶场：开源被测系统、在线练习环境 |

## 收录标准

- 优先收录：官方文档、活跃维护的开源项目、口碑稳定的经典书
- 商业课程谨慎收录，需注明性质与适用人群
- 链接失效请提 Issue，我们定期清理

欢迎推荐资源，参见[贡献指南](/about/contributing.html)。

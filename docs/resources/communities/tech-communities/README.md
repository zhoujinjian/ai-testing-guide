# 技术社区（已收录 12 个）

> 按社区属性分四组：**国内综合 → 测试垂直 → 厂商社区 → 国际社区**。每个社区独立一页：社区简介、基本信息、测试人怎么用。

**用法建议**：社区订阅贵精不贵多——**测试垂直**（TesterHome）+ **一个综合**（掘金或知乎）+ **一个厂商社区**（看你在用谁家云）+ **一个国际**（Stack Overflow 搜报错、X 追动态），四个刚好。信息流刷不完是焦虑的来源，不是学习的来源。

# 博客园

> 朴素但干货密度高的老牌博客平台。

## 社区简介

博客园（cnblogs）是 2004 年起的老牌中文博客平台——没有算法推荐、没有信息流，就是一篇篇工程师自己写的博客。测试方向的随笔和系列教程（Selenium、JMeter、pytest 的完整学习系列）很多，风格朴素，但**系列内容的完整度经常超过营销号十倍**。

## 测试人怎么用

- 搜「xxx 学习笔记 系列」——很多测试人把完整学习路径写成系列随笔
- 找 JMeter、Selenium 老问题的解决记录，命中率高
- 博客园的内容搜索引擎权重高，Google/Bing 搜中文测试问题常直接命中

# Stack Overflow

> 英文技术报错的第一搜索地，一搜一个准。

## 社区简介

Stack Overflow 是全球最大的程序员问答社区——二十年的高质量问答沉淀，几乎任何编程/工具/框架的报错和疑难都有人问过并得到了高质量回答。写自动化脚本（Playwright、Selenium、pytest）碰到的问题，英文错误信息直接搜这里，命中率高于任何中文社区。

## 测试人怎么用

- 报错信息直接英文原文搜索，配合 `site:stackoverflow.com` 精准命中
- 高票回答 + 高票评论一起看，很多坑在评论区补全
- 找不到答案再提问——先搜 Duplicate，社区对重复问题不友好

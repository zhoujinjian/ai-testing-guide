# TesterHome

> 国内测试技术讨论的专业主阵地。

## 社区简介

TesterHome（测试之家）是国内最专业的测试技术社区——话题围绕测试工程本身：自动化框架、测试平台、效能度量、AI 测试的**深度讨论**多发生在这里（很多测试开源项目的作者就在社区里答疑）。

每年主办 **MTSC 大会**（中国互联网测试开发大会），议题质量在测试圈是标杆；各城市的技术沙龙也活跃。

## 测试人怎么用

- 搜框架选型、平台建设类问题——评论区常有一线负责人的实操反馈
- 关注 MTSC 大会议题，每年测试方向的风向标

# 开源中国 OSC

> 国内开源资讯与项目发现的第一站。

## 社区简介

开源中国（OSChina）是老牌开源技术门户——开源资讯更新快（国内外项目动态、版本发布），旗下代码托管平台 **Gitee（码云）** 承载了大量国产开源测试工具（MeterSphere、RunnerGo、Apifox 早期都在 Gitee 有主页）。

## 测试人怎么用

- 看开源资讯里的「测试工具」类目，国产新工具的第一波曝光多在这里
- Gitee 搜「软件测试」「测试平台」，发现国内公司开源的测试工具
- 年度「开源项目评选」里翻测试类项目，是选型参考

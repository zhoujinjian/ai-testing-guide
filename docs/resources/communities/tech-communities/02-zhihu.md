# 知乎

> 搜测试相关的「怎么办」类问题，常在这里找到过来人的答案。

## 社区简介

知乎是中文最大的问答社区，「软件测试」「测试开发」话题下聚集了大量经验帖：转行路径、工具选型、踩坑复盘、职业选择。回答质量参差，但高赞回答的信息密度整体不错，是「经验类问题」的第一搜索阵地。

# Awesome Testing

> 测试工具界的「黄页」，找全栈测试工具从这里开始。

## 项目简介

Awesome Testing（TheJambo 维护）是最通用、最全的测试资源大清单，覆盖：**API 测试、E2E、移动端、性能、Mock、测试数据、AI 测试、安全测试、报告、CI 集成**——每个类目下按工具属性分组（开源/商业/SaaS），持续更新。

**对测开的价值**：里面收录了大量 API Agent、LLM 测试、流量录制、测试数据生成工具（Keploy、Bruno、k6 等），正好匹配 API Agent + 三层断言、测试数据生成的日常工作场景。

**适合**：找全栈测试工具、调研 API 自动化 / AI 测试工具选型的第一步——先在这里把候选清单拉全，再到本站[测试工具清单](../../test-tools/)看逐个工具的深度档案。

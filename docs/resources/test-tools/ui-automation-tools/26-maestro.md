# Maestro

> YAML 写用例，容忍延迟，不 flaky。

## 工具简介

Maestro 是轻量级的移动 UI 测试框架——用 YAML 写测试用例，单个二进制安装即用，不需要编译、不需要写代码。

它的设计哲学是**容忍 UI 延迟**：内置等待和重试策略，移动端常见的「元素还没渲染出来」导致的 flaky 它天然免疫。支持 iOS、Android（也可测 Web），命令行一条命令跑起来，配合 Maestro Cloud 做并行执行和报告。移动团队想快速把冒烟链路自动化，它是上手成本最低的那档。

## 工具简介

pywinauto 是 Python 的 Windows UI 自动化老牌库——支持 UIA 和 Win32 双后端，**控件级**的定位和操作（比 PyAutoGUI 的图像识别稳定得多），能拿到控件的属性做断言。

Windows 桌面产品的自动化测试（ERP 客户端、工业软件、安装程序）里它用得很多；录制工具 SWAPY 和文档配套齐全。局限：仅 Windows 平台。

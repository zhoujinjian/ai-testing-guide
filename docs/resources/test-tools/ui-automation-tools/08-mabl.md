# Mabl

> AI 自愈 SaaS，给 DevOps 团队省心用的。

## 工具简介

Mabl 是 SaaS 形态的低代码 Web 测试平台，AI 贯穿全程——元素变了自动修定位，视觉比对、性能回归、无障碍检查打包在里面，云上跑，给 DevOps 团队省心用的。

它解决的是定位器失效这个最磨人的维护项：治的是**维护的病**，治不了用例的病——用例设计、场景覆盖还是得人来，别指望 AI 帮你想该测什么。

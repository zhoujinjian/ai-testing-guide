# Nova Act（亚马逊）

![Nova Act](../../../assets/images/tools/nova-act.png)

> 官方示例直接演示 agent 调 IAM 管 S3。

## 工具简介

Nova Act 是亚马逊官方的浏览器 Agent SDK，Python 写的，底下包着 Playwright，深度绑定 AWS 生态——账号、权限、存储这些周边对 AWS 团队全是现成的。

它主打可靠：官方说法是**模型会对每步动作自评再执行**，长链条任务不容易跑偏。

# Robot Framework

![Robot Framework 仓库卡片](../../../assets/images/tools/robot-framework-og.png)

## 工具简介

Robot Framework 是 Python 系开源关键字驱动框架，表格化的用例业务人员也能读懂，插件生态覆盖 Web（SeleniumLibrary）、桌面、嵌入式——传统企业和银行保险业的常青树。

UI 自动化上，它通过不同 Library 驱动 Web、桌面（WhiteLibrary/FlaUILibrary）、移动端（AppiumLibrary），一套关键字体系多端复用。接口测试用法见[接口测试工具分类](../api-testing-tools/21-robot-framework-requests.md)。

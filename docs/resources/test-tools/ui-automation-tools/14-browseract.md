## 工具简介

BrowserAct 专攻反爬封锁——突破验证码和风控只是基础，细节做得比较全：任务卡住可以**暂停转人工**，人处理完接着跑，长任务不用人盯着；多任务并行、多账号会话隔离，采集和批量操作的重活扛得住，还提供 n8n 工作流组件接进现有自动化流程。

CLI 是商业产品，配套 Skill 仓库开源（2026 年 2 月建仓，七个月 6 千 star）。

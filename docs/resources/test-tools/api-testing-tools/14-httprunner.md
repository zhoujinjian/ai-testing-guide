## 工具简介

HttpRunner 是国产开源接口测试框架，用 YAML 或者 JSON 写用例，不写代码也能搭接口自动化——录屏转用例、参数化、耗时统计都有。

v4 用 Go 重写后性能和单文件分发都上来了，国内测试团队用得非常多，是低代码接口自动化的国产代表。

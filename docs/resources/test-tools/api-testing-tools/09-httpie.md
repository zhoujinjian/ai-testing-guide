## 工具简介

HTTPie 是给人类用的 HTTP 客户端——命令行里最舒服的那个，语法直觉到不用记，彩色输出，JSON 处理顺滑。

重写开源之后社区版很好用，写脚本做冒烟、教学生入门都是它。命令行做接口冒烟检查（比如部署完 curl 一圈），HTTPie 是体验最好的那一档。

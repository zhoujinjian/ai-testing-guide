## 工具简介

微软的 Playwright 除了驱动浏览器，还带一套 **request 上下文**——直接发 API 请求做断言，和 UI 测试同框混编。UI 前置造数用 API、UI 后置清理用 API，一个框架全搞定。

2026 年官方定位里 API 测试和 AI Agent 场景都是一等公民——对已经在用 Playwright 做 UI 自动化的团队，加接口能力是顺手的事。

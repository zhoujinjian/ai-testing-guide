## 工具简介

Apache JMeter 是 Apache 基金会的老牌开源，Java 写的，图形界面加协议全家桶——HTTP、JDBC、JMS、TCP 都能压。接口测试和性能测试一把抓，插件生态庞大，没编程背景的团队靠它吃饭。

缺点是重，高并发下自身资源占用偏高（分布式压测可解，详见性能测试工具分类）。

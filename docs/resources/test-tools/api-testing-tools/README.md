# 接口测试工具（规划中）

接口测试相关工具清单：接口调试与手工测试、接口自动化框架、抓包代理、Mock 服务。

## 计划收录

| 方向 | 候选工具 |
| --- | --- |
| 接口调试 | Postman、Apifox、Hoppscotch、HTTPie、Insomnia |
| 接口自动化 | HttpRunner、Karate、rest-assured、pytest + requests、Playwright API |
| 抓包代理 | Charles、Fiddler、mitmproxy、Whistle |
| Mock 服务 | WireMock、Mock.js、YApi、Apifox Mock |

> 本分类整理中，欢迎通过 Issue 或 PR 推荐工具，参见[贡献指南](/about/contributing.html)。已完成分类可参考 [AI 编程工具](../ai-coding-tools/) 的页面结构。

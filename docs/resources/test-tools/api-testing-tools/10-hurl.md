## 工具简介

Hurl 是基于 curl 的命令行测试工具，用例就是**纯文本文件**——一条请求一行，断言直接写在下面，人能读，git 能管，CI 能跑。

轻到没有存在感，但把「接口即代码」这条路走到了底。纯文本用例进 Git、走 PR、失败即日志，轻量项目真心推荐。

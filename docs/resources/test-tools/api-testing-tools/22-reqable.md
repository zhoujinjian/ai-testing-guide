## 工具简介

Reqable 是国产 API 调试与抓包一体化工具，由 HttpCanary 的作者出品——**接口调试（类 Postman）和流量抓包（类 Charles）做在同一个客户端里**，再加 API Mock 和重写规则，一条龙覆盖接口测试的日常。

跨平台（桌面 + 移动端抓包场景），免费额度对个人够用，中文界面友好。想在调试和抓包之间不来回切工具的测试同学可以重点关注。

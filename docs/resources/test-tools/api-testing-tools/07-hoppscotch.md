![Hoppscotch](../../../assets/images/tools/hoppscotch.png)

## 工具简介

Hoppscotch 是开源的网页版 Postman 替代，轻量到开箱即用，自部署一个就能给全团队用，数据在自己服务器上。

界面现代，支持 REST、GraphQL、WebSocket、SSE、MQTT 一大票协议，社区活跃——自部署 + 多协议是它对 Postman 的差异化。

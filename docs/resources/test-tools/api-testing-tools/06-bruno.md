## 工具简介

Bruno 是这波 Postman 收费潮里最大的受益者。开源免费跨平台，最大特点是**数据全部存本地文件夹**——天生跟 Git 亲和，团队协作靠仓库而不是云端，数据主权直接拿回来了。

支持前置后置脚本、断言、内置测试运行器，概念上就是本地化的 Postman。在意数据主权或只想零成本的团队，一分钱不花，用例还在自己手里。

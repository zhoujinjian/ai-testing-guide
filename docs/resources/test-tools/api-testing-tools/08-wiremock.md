# WireMock

![WireMock 仓库卡片](../../../assets/images/tools/wiremock-og.png)

> Mock 服务的事实标准，Java 生态亲儿子。

## 工具简介

严格说 WireMock 是 Mock 服务，但接口测试离了 Mock 根本跑不齐场景。WireMock 是这个领域的事实标准——stub、延迟、故障注入、录制回放都有，Java 生态亲儿子，独立部署也行，渗透在几乎所有接口测试流水线里。

依赖一堆第三方服务的接口测试，没有独立的 Mock 层根本稳定不下来——搭框架之前先把 Mock 想清楚，WireMock 就是那个默认答案。

## 工具简介

Apifox 的定位一句话说清：**Postman 加 Swagger 加 Mock 加 JMeter 的合体**——API 文档、调试、Mock、自动化测试、性能压测一套系统一份数据，中间不用来回导。

Apifox CLI 支持无头运行，直接挂 CI/CD。团队协作免费政策也比 Postman 厚道，这波迁移动作里吃到了最大红利。

## 收录标准

- 工具独立成页，英文 slug 命名文件，标题用工具官方名称
- 开源工具必须附仓库地址并核验其有效性（失效仓库不收录或标注）
- 商业产品标注「闭源」，注明官网与定价模式（免费额度 / 订阅 / 按量）

欢迎推荐工具，参见[贡献指南](/about/contributing.html)。

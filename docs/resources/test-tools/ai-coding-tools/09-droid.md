# Droid

![Droid](../../../assets/images/tools/droid.png)

> 企业级 coding agent 的代表，主打工程化。

## 工具简介

Droid 是 Factory 出品的企业级 coding agent，主打工程化，能在 CI 里稳定跑。它的 exec 模式不需要守护进程——一条命令拉起一个 agent 干活，自动化集成特别干净。

对想在流水线里嵌 agent 的团队（比如 CI 里让 agent 自动修失败用例），这是它的差异化卖点。

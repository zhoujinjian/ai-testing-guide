# Antigravity

> Google 去年 11 月发布的 agentic IDE，吸纳了 Windsurf 的原班人马。

## 工具简介

Antigravity 是 Google 的 agentic IDE，核心玩法是把任务丢给一个 **manager agent**，由它编排多个 agent 并行干活，你在旁边看产出就行——「指挥而不执行」的多 agent 协作模式。

目前免费用 Gemini，尝鲜成本低。

## 工具简介

Hermes 是 Nous Research 今年 2 月发布的开源自主 agent，带**持久记忆**——能从使用经验里自己攒技能，越用越懂你。口号是「the agent that grows with you」。

「越用越懂你」的学习型路线，和订阅制工具的「每次都从零开始」形成鲜明对比。

## 工具简介

OpenCode 是开源终端 agent 的底座级项目——模型随便换，TUI 界面漂亮，LSP 集成干净。小米的 Mimo、Kilo CLI 都是 fork 它，**被 fork 本身就是一种认证**。

想要一个「不绑定任何厂商、配置完全自己说了算」的终端 agent，从它起步最稳。

# Every Code

## 工具简介

Every Code 是 Codex CLI 的社区 fork，本地终端 agent。它的差异化在**代码 diff 分析**做得特别细——AI 改了什么、为什么改，给你解释得明明白白。

对重视「看清 AI 每一步改动」的团队（比如评审 AI 生成的测试脚本），这个能力很实用。

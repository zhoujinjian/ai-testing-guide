## 工具简介

Goose 是 Square 母公司 Block 开源的 agent 框架，扩展机制设计得很好，MCP 生态玩得早。后来 Block 把它捐给基金会独立运营——大厂开源里少见的「**真开源**」，社区氛围好。

适合想把 agent 能力嵌进自己工具链（比如测试平台里嵌 agent 跑用例修复）的团队。

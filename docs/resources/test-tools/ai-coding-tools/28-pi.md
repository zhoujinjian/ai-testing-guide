## 工具简介

pi 是极简 agent harness 的代表——system prompt 才几千 token，把省 token 做到了极致，反而换来了最强的可定制性：Extensions、Skills、模板随便改。

口号很傲娇：「有很多 agent 框架，但这个是你的」。它的社区 fork OMP（见 [OMP](./29-omp.md)）反而长成了大热门。

## 工具简介

Gemini CLI 是 Google 官方的开源终端 agent，Apache 协议，免费额度出了名的大方，个人开发者每天能免费用的量相当可观，是预算敏感开发者的首选之一。

多模态是它的独门优势——看图写代码、对着截图改 UI 这类活它最顺手。对测试开发而言，「扔一张 UI 截图让它生成/修正定位和断言」是很典型的用法。

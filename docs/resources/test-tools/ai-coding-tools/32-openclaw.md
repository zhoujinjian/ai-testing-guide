## 工具简介

OpenClaw 是开源个人 agent，24 小时挂在服务器上替你干活，WhatsApp、Telegram 都能接——「常驻型个人助理」的路线。

今年年初最出圈也最有争议的一个，安全问题讨论很多。玩之前建议先读读它的权限设计——授权范围要想清楚再给。

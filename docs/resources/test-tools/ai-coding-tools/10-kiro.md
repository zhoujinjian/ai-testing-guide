## 工具简介

Kiro 是亚马逊的 spec 驱动 IDE：先写**需求、设计、任务**三段式规格，agent 照着规格干活。等于把研发流程本身管了起来。

这个模式特别适合团队协作和对交付质量有要求的场景——规格先行、按规格验收，和测试左移的思路天然契合（规格即可测性依据）。

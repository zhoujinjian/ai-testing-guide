## 工具简介

Cline 是 VS Code 开源 agent 插件的祖师爷——计划和执行双模式的开创者，MCP 协议的早期推动者。后面的 Roo Code、Kilo Code 都是从它长出来的后代。

开源、免费、自带 Key 即用，是「不绑订阅」路线的起点级项目。

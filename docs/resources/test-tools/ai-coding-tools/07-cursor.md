## 工具简介

Cursor 是 Anysphere 出品的 AI 原生 IDE，编辑器派的门面担当。Tab 补全的预测式编辑加上 Composer 的任务式生成，把「AI 写代码」的体验做成了行业标杆，营收增长是整个硅谷的神话级故事。

几乎所有后来者的 IDE 产品都在对标它的交互范式。

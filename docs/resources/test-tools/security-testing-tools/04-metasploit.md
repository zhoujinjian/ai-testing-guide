## 工具简介

Metasploit 是 Rapid7 维护的漏洞利用框架——**全球最大的 Payload 库**，从侦察到利用到后渗透一条龙（msfconsole 的模块化工作流）。

学渗透必学它：漏洞的「可利用性验证」（不是扫描器报个高危，是真的打进去证明）靠它完成。授权渗透测试和红队演练的基础设施。

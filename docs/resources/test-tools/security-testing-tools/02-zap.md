## 工具简介

OWASP ZAP 是 OWASP 基金会的开源 Web 漏洞扫描器，Burp 最有名的免费平替——主动被动扫描、拦截代理、爬虫、Fuzz 一应俱全，**headless 模式直接进 CI/CD 流水线**，DevSecOps 场景引用量第一。

「ZAP 卡部署」是安全左移的主力打法：流水线里挂 ZAP 扫描，部署完自动过一遍，高危即卡点。预算有限团队的起步答案。

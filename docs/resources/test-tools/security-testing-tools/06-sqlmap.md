## 工具简介

sqlmap 是 SQL 注入自动化检测与利用的神器——支持几乎所有主流数据库（MySQL、PostgreSQL、Oracle、SQL Server……），从指纹识别到数据提取（拖库）一条龙。

典型工作流：Burp 里手工确认疑似注入点 → sqlmap 接手自动化利用验证。对测试工程师，它也是理解注入危害的最佳教材（授权环境下）。

## 工具简介

Xray 是长亭科技出品的漏洞扫描器，国产安全圈的口碑产品——**被动代理扫描是招牌**：挂在浏览器或 Burp 下游，正常测试的流量过一遍就出洞（不改变测试节奏的前提下持续扫描），和 Burp 联动是国产渗透的常见组合。

社区版免费（内置漏洞类型够用），企业版带更多 PoC 和管理能力。

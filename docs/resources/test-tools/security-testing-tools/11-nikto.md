## 工具简介

Nikto 是二十年历史的老牌 Web 服务器扫描器——**危险文件、过期组件、配置问题**（目录列表、默认后台、不安全 header）一遍过。

误报偏多（「吵」），但速度快、覆盖面稳，资产初筛阶段先把明显问题过一遍的敲门砖。和 Nuclei 的分工：Nikto 管配置类问题，Nuclei 管 CVE 情报。

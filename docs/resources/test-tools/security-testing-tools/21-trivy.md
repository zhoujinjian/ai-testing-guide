## 工具简介

Trivy 是 Aqua Security 开源的一体化安全扫描器——**容器镜像、Kubernetes、代码仓库依赖、IaC 配置（Terraform 等）、文件系统**全都能扫：OS 包漏洞、语言依赖漏洞、错误配置三类问题一个工具覆盖。

特点是快（一次镜像扫描秒级）和 CI 集成方便（exit code 直接做卡点），2026 年容器安全工具榜的常驻前排。有容器的团队，流水线里挂 Trivy 是标配动作。

# Acunetix（AWVS）

> 商业扫描器里的误报控制标杆。

## 工具简介

Acunetix（老牌 AWVS 的现在式）是 Invicti 旗下的商业 Web 漏洞扫描器——**扫描深度和误报控制在商业产品里是标杆**，IaC 扫描、API 测试也整合了，企业合规输出的常选。

买商业扫描器主要买的是误报率和报告合规性（等保、ISO 审计认它的报告），这是开源扫描器补不上的位。

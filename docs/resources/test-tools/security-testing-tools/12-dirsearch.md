## 工具简介

dirsearch 是 Python 写的目录暴破工具——字典管理友好（自带常用字典、递归探测、后缀扩展），多线程，结果直观（彩色输出 + 报告导出）。

渗透测试里找后台入口、找备份文件、找敏感路径（/.git/、/.env/）的日常工具，Python 环境装完即用，上手比 Go 系工具更贴近脚本党。

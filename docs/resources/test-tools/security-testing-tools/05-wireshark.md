# Wireshark

![Wireshark 仓库卡片](../../../assets/images/tools/wireshark-og.png)

> 二十多年了，这个位置没有挑战者。

## 工具简介

Wireshark 是协议级抓包分析的天花板——网络排障和安全分析两头吃，**过滤器语言是门手艺**（display filter + capture filter），学会了看什么流量都透明。

对测试工程师，它是「底层发生了什么」的最终答案：TLS 握手、TCP 重传、DNS 解析，应用层说不清的问题抓包层见真章。

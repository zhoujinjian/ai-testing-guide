> Fuzz 工具的速度王者。

## 工具简介

ffuf 是 Go 写的快速 Fuzz 工具——目录暴破、参数 Fuzz、子域名枚举一通百通，速度和扩展性把老前辈们拍在沙滩上，**递归目录探测和多种匹配模式**（状态码、字节数、正则）齐全。

配合递归模式 + 合理字典，目录探测一轮出结果；过滤器（-fc/-fs）滤掉误报是它的核心用法。Kali 出厂标配。

## 工具简介

Hydra（THC-Hydra）是弱口令暴破的经典工具——**数十种协议**的并行登录爆破（SSH、FTP、HTTP 表单、RDP、SMB、MySQL、Redis……），支持字典和组合规则，分布式多目标。

安全测评里「弱口令排查」这一项的实际验证工具：拿授权资产清单 + 常用口令字典跑一遍，比人工抽查可信。十年常青，Kali 内置。

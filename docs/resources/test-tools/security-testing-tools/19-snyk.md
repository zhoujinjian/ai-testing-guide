## 工具简介

Snyk 是供应链安全的代表——**依赖组件漏洞扫描（SCA）起家**，容器镜像和 IaC 也管了，从 IDE 插件到 CI 到运行时一路覆盖。

「Snyk 卡依赖」是安全左移三件套之一：开源依赖占比越来越高的今天，第三方组件的已知漏洞（Log4j 式的雷）靠它持续盯。对开源项目有免费额度。

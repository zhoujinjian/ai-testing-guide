## 工具简介

Locust 是 Python 生态的压测代表——用代码定义用户行为，分布式扩容开箱即用，Web 界面实时看曲线。会 Python 的团队用它写复杂业务模型特别顺手（登录、浏览、下单的流量配比随意编排）。

缺点是单进程性能一般，大规模要靠多进程堆（官方的分布式 worker 机制就是为此设计）。

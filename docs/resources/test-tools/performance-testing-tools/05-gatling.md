## 工具简介

Gatling 是 Scala 写的高性能压测框架——DSL 简洁，报告是所有工具里最好看的一档，实时指标动效拉满，欧洲公司用得特别多。

开源版够用，企业版带集群和监控。JVM 系技术栈团队在 k6（JS）和 Gatling（Scala/Java）之间二选一时，它对 Java 团队更亲和。

## 工具简介

阿里云 PTS（性能测试服务）是云上全链路压测服务——免搭建压测机集群，流量从云内发起更真实，施压配置、监控、报告全托管，跟阿里云生态深度绑定，**双十一级别的大促演练就是拿它跑的**。

按量计费，临时大促场景特别划算。机房内自压永远打不出真实公网流量形态——「从哪发压」这件事，云 PTS 的价值就在这里。

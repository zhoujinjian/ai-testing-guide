# oha

![oha 仓库卡片](../../../assets/images/tools/oha-og.png)

> Rust 版 hey，终端里实时看曲线。

## 工具简介

oha 是 Rust 写的 HTTP 压测工具（hey 的现代化替代）——命令行 TUI 界面**实时显示延迟曲线和分位数**，输出体验比 hey 直观一代。

2026 年多篇工程文档把它和 k6 并列推荐为轻量方案（「k6 or oha」）：摸底快测用 oha，场景化压测上 k6。单 Rust 二进制，无依赖。

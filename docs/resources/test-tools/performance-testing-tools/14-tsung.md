# Tsung

> Erlang 多协议，IM 类系统的压测老牌答案。

## 工具简介

Tsung 是 Erlang 写的多协议压测工具——HTTP 之外，**XMPP、MQTT、WebSocket、AMQP、PostgreSQL、MySQL** 都能压，Erlang 的轻量进程模型让它单机能模拟海量长连接。

即时通讯、推送、IoT 这类非纯 HTTP 系统的压测，它是多年的老牌答案；XML 配置场景的方式比较上古，但协议覆盖至今没有完美替代。

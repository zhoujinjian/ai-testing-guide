# LoadRunner

> 企业级性能测试的老钱，协议录制至今无人能敌。

## 工具简介

LoadRunner 现在归 OpenText，是企业级性能测试的老钱——TruClient 对复杂前端的录制回放、海量协议支持、分析报告深度，都是金融电信这类大厂离不开它的理由。

缺点就一个字：贵。中小企业基本无缘，但它的场景库和方法论（负载模型、分析报告范式）至今是行业的参照系。

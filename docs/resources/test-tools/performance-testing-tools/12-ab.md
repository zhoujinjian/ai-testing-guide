# ab（ApacheBench）

> 最经典，装机自带，一条命令出 RPS。

## 工具简介

ab（ApacheBench）是最经典的 HTTP 压测工具，随 Apache HTTP Server 发布——大量 Linux 发行版装机自带，`ab -n 1000 -c 100 https://...` 一条命令就出 RPS 和简单分位。

输出原始（没有直方图和 P99 细分）、不支持复杂场景，但**零安装成本**使它至今仍是「进门先来一发」的参照工具。现代替代见 [hey](./09-hey.md) 和 [oha](./11-oha.md)。

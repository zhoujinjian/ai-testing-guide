## 工具简介

BlazeMeter 是 Perforce 旗下的 SaaS 压测平台——最大的卖点是 **JMeter 脚本直接上云**，弹性扩到几十万并发，录制回放、Mock、监控一体，和 Jenkins 等 CI 工具集成成熟，外企和大厂海外团队用得多。

存量 JMeter 脚本想做大规模分布式施压又不养机房，它是最顺的迁移路径。

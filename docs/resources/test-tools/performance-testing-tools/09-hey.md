# hey

> 装机常备的快测工具。

## 工具简介

hey 是 Go 写的 ab 替代品——一条命令看 QPS 和延迟分位，比 ab 的输出友好（直方图、分位数齐全），比 wrk 的功能简单（不用写 lua）。

单二进制分发、无依赖，「随手压一下看看」的场景它最合适。JBD（Jaana Dogan，前 Google SRE）出品，工程圈装机常备。

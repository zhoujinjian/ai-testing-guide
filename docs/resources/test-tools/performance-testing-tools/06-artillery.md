# Artillery

> 十几行 YAML 起一个带思考时间的真实用户模型。

## 工具简介

Artillery 是 Node.js 生态的压测工具——YAML 写场景，十几行就能起一个带思考时间的真实用户模型，**门槛是所有代码系里最低的**。

小团队快速验证够用，超大规模不是它的主场（Node 运行时的天花板在那里）。Node 技术栈团队想要「像写配置一样写压测」，它比直接上 k6 更友好。

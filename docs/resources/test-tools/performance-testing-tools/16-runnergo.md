## 工具简介

RunnerGo 是国产开源的全栈式测试平台，Go 语言开发——接口管理、场景自动化、性能压测一个平台全管，**六种压测模式**（连错误率模式和响应时间模式都有），轻量好部署，对国内团队的网络环境友好。

想要国产开源的「接口 + 压测」一体化平台（对标 MeterSphere 的轻量版路线），它是近年的新选项。

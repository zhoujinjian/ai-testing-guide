# wrk

> 做容量摸底，一轮就知道服务器的底在哪。

## 工具简介

wrk 是 C 写的 HTTP 基准测试神器——单机就能打出恐怖的并发，自带 lua 扩展钩子（自定义请求、动态参数、延迟分段统计），做容量摸底一轮就知道服务器的底在哪。

**wrk2 变体**解决了原版协同遗漏（coordinated omission）的延迟测量问题——在高负载下主动补发请求，测出的 P99 才是真 P99。对延迟分位数敏感的场景（直播、交易），摸底用 wrk2 更严谨。

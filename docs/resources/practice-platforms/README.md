# 练手平台与靶场（规划中）

练手用的被测系统与靶场：自动化练习、接口练习、安全靶场，与路线实战项目配套。

## 计划收录方向

| 方向 | 候选 |
| --- | --- |
| Web 被测系统 | the-internet、OrangeHRM、Petclinic、Swagger Petstore |
| 电商与业务系统 | Mall、litemall、Tapir（被测商城） |
| 安全靶场 | DVWA、Juice Shop、Pikachu、bwapp |
| 接口练习 | JSONPlaceholder、httpbin、Reqres |
| Bug 演练 | 腾讯 WeBug、开源缺陷演练系统 |

> 本分类整理中，欢迎通过 Issue 或 PR 推荐，参见[贡献指南](/about/contributing.html)。收录原则：可本地部署或免费在线、维护活跃、缺陷类型有代表性。

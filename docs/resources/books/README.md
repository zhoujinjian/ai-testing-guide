# 推荐书单（规划中）

测试开发方向的书单，按学习阶段与主题组织，与路线各章配套。

## 计划收录方向

| 方向 | 主题 |
| --- | --- |
| 测试理论 | 软件测试基础、测试设计方法、探索式测试 |
| 自动化 | 自动化框架设计、测试金字塔、代码质量 |
| 性能与安全 | 性能测试方法学、Web 安全基础 |
| 质量工程 | 持续交付、DevOps、研发效能 |
| AI 测试 | 大模型评测、AI 辅助研发 |

> 本分类整理中，欢迎通过 Issue 或 PR 推荐，参见[贡献指南](/about/contributing.html)。收录原则：优先经典与口碑稳定的书，标注适用阶段与阅读优先级。

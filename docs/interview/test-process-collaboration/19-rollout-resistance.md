# 19｜团队里要推行一个新流程或新工具，同事有抵触，你怎么办？

> 开场先讲对抵触的理解，这决定后面的姿态：**抵触是合理的**（新流程意味着学习成本和舒适区打破，人是理性的抗拒不是故意作对），先共情再推。**把抵触当信息**——抵触的点往往就是方案的真问题，**别人的质疑是免费的评审**。这个认知高度是这题的第一分。

## 回答思路

### 第一步：讲推广的策略组合

- **参与感**：方案共创，让未来要遵守规则的人参与定规则——自己参与定的规则不会抵触
- **试点**：先在小范围跑，效果数据说话——「试点组的回归时间省了一半」比任何说服都硬
- **降成本**：新流程的工具配套做齐，checklist 模板自动化脚本都备好，**让别人用新方法比旧方法更省力**，推广就成功了大半
- **找盟友**：团队里有影响力的人先用起来——同侪示范比领导命令有效

### 第二步：讲不同的抵触类型分别对待

- **能力型抵触**（不会用）：培训加陪跑解决
- **利益型抵触**（新流程动了他的舒适区或工作量）：调整方案让成本分摊合理或给激励
- **观念型抵触**（不认同理念）：用数据和案例慢慢影响，不求一次说服

分类应对比一刀切有效。

### 第三步：讲组织资源的借力

确实需要行政推动的（涉及规范的强制项，如安全红线），借助管理层的正式授权——但**授权是底线保障不是首选手段**（命令能让人服从不能让人认同，认同才能长期执行）。

### 收尾：讲复盘

推广后要复盘**采纳数据**（多少人真用起来了、哪些环节没人遵守、为什么），持续迭代方案——**推广本身是个产品迭代过程**，「发布了就是推广了」是常见错误。

## 考察重点

| 维度 | 说明 |
| --- | --- |
| 企业动机 | 流程和工具的落地阻力是所有团队的常态（推广能力是资深测试的软技能硬指标），这题考察「推动的艺术」——只会「找领导压」的和只会「发个通知」的都推不动事，企业要能靠自己让事情发生的人 |
| 过线标准 | 参与感试点降成本盟友的策略组合 + 抵触分类应对 |
| 区分度 | 讲「抵触是免费评审」、讲复盘采纳数据的推广产品观是有多次推动经验的 |
| 加分项 | 行政授权是底线保障不是首选的权力观 |
| 减分项 | 「不愿意用就算了」（没有推动力）或「强制要求必须用」（只有权力没有方法）——两个极端都推不成事 |

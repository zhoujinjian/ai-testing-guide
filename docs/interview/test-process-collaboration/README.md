# 测试流程与团队协作面试题

> 题目整理自知识星球《面试情报 10｜测试流程与团队协作 20 题》，来自企业面试真实出现过的题目（霍格沃兹测试流程面试题库、知乎和阿里云「介绍测试流程」标准框架、小林 coding 回归测试专项、牛客阿里测开面经的项目流程真题、CSDN 敏捷与瀑布区分度考点），按面试真实展开顺序分为三组：**流程环节深挖 → 跨角色协作 → 流程改进与情境**。[软件测试必备](../testing-essentials/)讲了流程的个人基础版，[测试管理](../test-management/)讲了管理者的团队版，这一篇是中间那层——把流程的每个环节问透，把测试和产品、开发、跨团队的协作问透，对应 3 到 5 年经验的中级测试和测开面试。

**用法建议**：别背答案。每道题先自己口述一遍，再对照回答思路找缺口——答到点上比答得多重要。技术面过了挂在流程深度和协作题上的人不少，这一篇补的就是这块。每题的「区分度」和「加减分项」就是面完自查的清单。

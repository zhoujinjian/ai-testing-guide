这个目录用于建设分类的测试开发面试题库，与路线 [第 13 章面试准备](../roadmap/13-interview-guide.md) 配套：第 13 章讲方法，这里沉淀真题和参考回答。

## 规划结构

```
interview/
├── README.md           # 本文件：题库导航
├── theory.md           # 测试理论与场景设计题
├── automation.md       # 自动化框架与工程题
├── performance.md      # 性能与排障题
├── ai-testing.md       # AI 辅助测试与 AI 应用评测题
└── hr-and-career.md    # 项目表达、职业规划类问题
```

## 收录标准

- 真实面经里出现过的题目（请注明来源类型：校招 / 社招 / 大厂 / 创业公司）
- 参考回答要求：先给回答框架，再给要点展开，不鼓励背诵式答案
- 欢迎通过 Issue 或 PR 提交你遇到的真实面试题，参见[贡献指南](../../CONTRIBUTING.md)

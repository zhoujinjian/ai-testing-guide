# 面试题库

> 本站题库只挑选了少量高频题，帮你快速建立答题思路。**更多精选大厂面试真题与在线刷题练习**，请前往 [AI 测开导航 · 面试刷题](https://www.testfather.cn/interviews) 学习。

题库与路线 [第 13 章面试准备](../roadmap/13-interview-guide.md) 配套：第 13 章讲方法，这里沉淀**真题和参考回答**。每题固定结构：一句话定调 → 回答思路（分层展开）→ 考察重点（企业动机 / 过线标准 / 区分度 / 加减分项）。

> 用法建议：别背答案。每道题先自己口述一遍，再对照回答思路找缺口——答到点上比答得多重要。

## 收录标准

- 真实面经里出现过的题目（注明来源类型：校招 / 社招 / 大厂 / 创业公司）
- 参考回答要求：先给回答框架，再给要点展开，不鼓励背诵式答案
- 每题独立一个 Markdown 文件，英文 slug 命名，标题用中文
- 欢迎通过 Issue 或 PR 提交你遇到的真实面试题，参见[贡献指南](/about/contributing.html)

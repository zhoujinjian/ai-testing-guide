# 04｜团队成员能力参差不齐，怎么培养和分工？

> 开场先讲**人才盘点这个动作**——盘点先于分工，没有画像的分工是平均主义或印象流。

## 回答思路

### 第一步：按「能力 × 意愿」给团队画像

| 象限 | 打法 |
| --- | --- |
| 高能力高意愿（**核心骨干**） | 给舞台——牵头专项和带新人，用挑战留人 |
| 低能力高意愿（**潜力股**） | 给培养——导师制加轮岗加培训，重点投资 |
| 高能力低意愿（**倦怠者**） | 先谈心找原因——调岗换项目激活，或坦诚沟通去留 |
| 双低（待观察） | 限期改善或调整 |

### 第二步：讲分工的原则

- **按优势分**（擅长自动化的做工具建设、业务理解深的守核心业务），而不是按资历分
- **按发展分**（给成长空间——一直做舒适区的事的人会退化）
- **关键业务有备份**（核心模块至少两人会，防人员单点）

分工是团队效能和个体发展的平衡术。

### 第三步：讲培养的机制化而非人治

- **能力模型**（从初级到高级的技能清单，晋升有据可依）
- **定期一对一**（每月至少一次，谈成长不谈任务）
- **学习机制**（技术分享会、外部培训资源）
- **反馈闭环**（季度绩效面谈把发展聊透）

**机制在，人的成长不依赖管理者的个人勤快。**

### 收尾：给一个现实认知

培养人最大的风险是「培养了留不住」——正确的应对不是不培养（不培养的人留得更少），而是「**培养速度大于流失速度**」的池子逻辑，同时给成长和留下各自的好理由（成长空间加团队氛围）。**这个坦然是管理者必经的心智升级。**

## 考察重点

| 维度 | 说明 |
| --- | --- |
| 企业动机 | 能力参差是所有团队的常态——看你是「有方法地带」还是「自然生长地放」，前者才叫管理 |
| 过线标准 | 盘点画像 + 分层培养 + 分工原则 |
| 区分度 | 讲倦怠者激活、讲关键业务备份、讲「培养速度大于流失速度」的是有真实带队经验的 |
| 加分项 | 培养机制化（不依赖个人勤快）的设计意识 |
| 减分项 | 培养就是「让他多干点活自然就会了」，放养式管理的懒政 |

# 测试管理面试题

> 题目整理自知识星球《面试情报 09｜测试管理 20 题》，来自企业面试真实出现过的题目（全民简历 50 道测试经理面试题、CSDN 测试经理组长主管专项面试题、腾讯云测试 Leader 怎么做、阿里云测试价值衡量真题盘点），按面试真实展开顺序分为四组：**角色与团队 → 过程与项目 → 组织协作 → 价值与转型**。

**用法建议**：别背答案。管理岗面试没有标准答案，但有**标准事故**——踩过坑和没踩过坑的人，一开口就听出来了。每道题建议准备好自己团队的真实案例（脱敏后的），**管理岗面试没有案例等于裸考**。

# 15｜外包测试怎么管理？和自建团队怎么配比？

> 开场先讲外包的**定位设计**：外包的核心价值是**弹性**（业务波动时的人力缓冲）和**成本**（标准化执行的降本）；**核心价值不外包**（测试策略、质量标准、核心业务的深度测试、体系建设的判断）。定位清楚了，配比和管理的原则都有了主心骨。

## 回答思路

### 第一步：自建和外包的分工模型（配比的前提）

| 模型 | 适用 |
| --- | --- |
| **核心自建加外围外包** | 核心业务和策略自建、回归执行和兼容测试外包 |
| **按能力分层** | 自建团队做设计和判断、外包做执行和铺量 |
| **按波动调节** | 基线需求自建撑、峰值需求外包顶 |

### 第二步：讲外包管理的机制

- **准入和培养**：外包也要培训和考核——进项目的标准一致
- **过程的融合**：工具平台统一、流程统一、standup 一起开——**物理隔离是质量割裂的开始**
- **质量的抽检**：外包的测试产物定期抽检，验收标准清单化
- **边界的清晰**：权限和数据的安全管理，外包接触的数据范围明确——**安全合规的红线**

### 第三步：讲激励和稳定性

- 外包的**激励设计**（优秀外包的认可机制——别让「二等公民」感摧毁执行质量）
- **稳定性的管理**（核心外包的续约优先——换人频繁的知识流失比省的钱贵）
- **上升通道**（表现好的外包转正或转更核心模块——池子里捞人才）

### 收尾：给一个诚实的风险清单（权衡过的结论）

- **能力天花板**：策略性工作做不了，别期待错位
- **保密风险**：核心数据和代码的暴露面，合规审查要过
- **依赖风险**：外包占比过高的团队，供应商涨价或撤场就是灾难

配比建议：**执行层可以大头外包，判断层必须自建掌控。**

## 考察重点

| 维度 | 说明 |
| --- | --- |
| 企业动机 | 降本压力下测试外包是普遍现实——外包管不好是双输（质量差成本反而高），有外包管理经验的管理者在市场上是刚需 |
| 过线标准 | 定位和分工模型 + 管理机制 + 风险清单 |
| 区分度 | 讲外包转正通道、讲依赖风险的配比原则的是深谙外包生态的 |
| 加分项 | 数据安全合规红线的显式管理 |
| 减分项 | 「外包就是便宜劳动力随便用」——既不懂管理也不懂风险的傲慢答案 |

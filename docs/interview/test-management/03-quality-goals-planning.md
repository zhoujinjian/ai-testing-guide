# 03｜怎么制定测试团队的质量目标和年度规划？

> 开场先讲目标的**来源逻辑**：从上往下承接 + 从下往上对齐——不是拍脑袋列愿望清单。

## 回答思路

### 第一步：三源交叉定目标

1. **上级和业务的目标**（公司要增长要控风险——测试的目标要挂上去，比如大促保障、交付提效）
2. **团队的真实短板**（摸底发现的逃逸率高、自动化率低）
3. **行业的对标差距**（DORA 和逃逸率的参考段位，合集七的知识在这复用）

### 第二步：目标的结构化设计（三层缺一不可）

| 层 | 例子 |
| --- | --- |
| **结果指标** | 逃逸率降到多少、线上故障数、交付周期 |
| **过程指标** | 自动化覆盖率、需求测试参与率 |
| **能力建设** | 工具平台、人才培养 |

**只有结果指标团队不知道怎么干、只有过程指标容易假忙**——年度规划就是三条线的组合。

### 第三步：讲目标的合理性校验

- **有基线**（现在的数据是什么——没基线的目标是空想）
- **可达成**（跳一跳够得着——连续完不成的目标会摧毁团队信心）
- **有取舍**（资源有限，三个重点足够——什么都想要等于什么都一般）

### 第四步：讲规划到执行的分解

年度目标 → 季度里程碑（Q1 建基线和机制、Q2 见初步效果、Q3 复盘调优、Q4 收官验证）→ 具体项目（各有 owner 和时间表）。**没有分解的规划是墙上标语。**

### 收尾：讲动态调整的机制

季度复盘目标完成度和环境变化（业务方向变了目标要跟着调）——**规划的严肃性在于认真定和认真复盘，不在于一年不许改。**

## 考察重点

| 维度 | 说明 |
| --- | --- |
| 企业动机 | 定规划和定目标是管理者的核心产出——看你的目标管理能力是「科学方法」还是「表忠心式拍数字」，后者会把团队带沟里 |
| 过线标准 | 三源交叉 + 结果过程能力三层结构 |
| 区分度 | 讲基线校验、讲季度分解、讲动态调整的是真做过年度规划的 |
| 加分项 | 目标要挂业务战略的承接逻辑 |
| 减分项 | 目标就是「加强测试质量提升团队水平」这类正确的废话，没有指标没有路径 |

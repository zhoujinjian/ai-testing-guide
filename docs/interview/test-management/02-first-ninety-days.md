# 02｜新接手一个测试团队，前三个月你会做什么？

> 开场分阶段给路线图——空降管理者的死亡率极高（团队抵触、上级失望、自己挫败），**先看懂再动手**。

## 回答思路

### 第一步：三个月路线图

| 阶段 | 做什么 |
| --- | --- |
| **第一个月：摸底**（不动组织不动流程） | 一对一聊遍所有成员（做什么、擅长什么、苦恼什么、期望什么）、盘家底（项目、流程、工具、历史质量数据）、看现场（跟一次完整版本、参加需求和 bug 评审） |
| **第二个月：诊断加小胜** | 从摸底信息里找真问题（流程乱、能力弱还是士气低——病因不同药方不同）；挑一两个「痛但可解」的问题快速改善（提测质量差就推冒烟门禁，两周见效）——**小胜建立信任，比宏大规划有用** |
| **第三个月：规划铺开** | 和上级对齐期望、出团队规划（目标、路径、资源）、和协作方建立接口 |

### 第二步：讲三个「不要」（新任管理者的经典避坑清单）

1. **不要急着换人**（哪怕看着不顺眼——信息不全时的人事判断容易错）
2. **不要全盘否定前任**（存在即合理——先理解为什么这样，再判断要不要改）
3. **不要急着推大变革**（信任没建立前，推什么都被抵触）

### 收尾：讲一个关键判断

**先赢得团队还是先赢得上级？** 答案是先团队（团队信你，活能干好，上级自然满意；先讨好上级压团队干活，两头落空）——但要让上级「**看得见你在做什么**」（每周同步摸底发现和行动计划）。**向下扎根，向上透明。**

## 考察重点

| 维度 | 说明 |
| --- | --- |
| 企业动机 | 考察有没有系统的入场方法论还是凭感觉乱动——前者至少活下来的概率高 |
| 过线标准 | 分阶段路线 + 三个不要 |
| 区分度 | 讲「小胜建信任」、讲「先团队后上级但向上透明」的是有真实带团队智慧的 |
| 加分项 | 先理解存在再判断变革的克制 |
| 减分项 | 第一个月就大改流程换人——「新官三把火」烧向团队的莽撞答案 |

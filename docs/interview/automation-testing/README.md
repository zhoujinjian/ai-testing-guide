# 自动化测试面试题

> 题目整理自知识星球《面试情报 03｜自动化测试 20 题》，全部来自企业面试真实出现过的题目（阿里、字节自动化测试面试真题盘点、霍格沃兹面试题库、牛客大厂真题汇总里反复出现），按面试真实展开顺序分为四组：**认知策略 → Web 自动化技术 → 框架工程化 → 接口与移动端**。

**用法建议**：别背答案。每道题先自己口述一遍，再对照回答思路找缺口。自动化是这几年测试岗的第一诉求——这 20 题决定你能不能从功能测试迈进测试开发的门。

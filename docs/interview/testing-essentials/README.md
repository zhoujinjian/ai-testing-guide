# 软件测试必备面试题

> 题目整理自知识星球《面试情报 02｜软件测试必备 20 题》，全部来自企业面试真实出现过的题目，按面试真实展开顺序分为五组：**流程用例 → 缺陷管理 → 技术基本功 → 自动化 → 质量判断**。

**用法建议**：别背答案。每道题先自己口述一遍，再对照回答思路找缺口。这 20 题是所有测试岗的地基——不管你面的是功能测试、测试开发还是 AI 测试，都绕不开。

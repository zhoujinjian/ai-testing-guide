# 11｜App 测试和 Web 测试有什么区别？App 专项测试怎么做？

> 开场把区别按层次讲，然后进入** App 专项测试**展开——这是本题的得分主体。

## 回答思路

### 第一步：区别按三层讲

| 维度 | Web | App |
| --- | --- | --- |
| **系统环境** | 主要看浏览器 | 机型、分辨率、操作系统版本的碎片化 |
| **网络环境** | 相对少 | 移动网络是常态，弱网、断网、网络切换必须测 |
| **更新机制** | 发版即生效 | 有审核周期和版本碎片，老版本用户长期存在，兼容和强制升级策略都要测 |

### 第二步：App 专项测试展开（得分主体）

| 专项 | 测什么 |
| --- | --- |
| **兼容性** | 机型、系统版本、分辨率、厂商 ROM |
| **弱网和断网** | 2G/3G/弱 Wifi、丢包、超时的表现；断网恢复后能否续传 |
| **中断测试** | 来电、短信、弹窗、锁屏、切后台后回来状态是否保留 |
| **耗电和流量** | 后台偷跑、异常耗电 |
| **内存和性能** | 内存泄漏、卡顿、崩溃率、ANR |
| **安装卸载升级** | 覆盖安装数据保留、卸载干净、低版本升上来 |

### 第三步：H5 混合页面单独点一句

App 里嵌 H5 的要两层看：原生容器一层、Web 内容一层，出问题先分清在哪层（呼应 07 题的定位思路）。

### 收尾：讲工具落地

兼容用**云真机平台**，弱网用 **Charles 限速**或系统开发者选项，耗电流量用 **adb 和 perfetto** 分析——报得出工具名可信度翻倍。

## 考察重点

| 维度 | 说明 |
| --- | --- |
| 企业动机 | 移动端是多数业务的主阵地，这题考察移动端测试的体系化认知——只会功能点点点而不知道专项的，到了 App 项目要重新带 |
| 过线标准 | 区别讲到环境和更新机制，专项至少说出兼容、弱网、中断三类 |
| 区分度 | 讲崩溃率、ANR、内存泄漏这些性能专项的，是做过 App 深度测试的；只讲「App 要装在手机上」这种表层区别的，没做过移动端 |
| 加分项 | 云真机平台、adb、perfetto 这些工具脱口而出 |
| 减分项 | 专项测试一个都说不出来，说明移动端经验基本为零 |

# 08｜压测在什么环境做？测试环境压的数据能信吗？

> 开场先摆三种选择的利弊，再讲选型逻辑——线下绿灯线上翻车是要背事故的。

## 回答思路

### 第一步：三种环境各说一句利弊

| 环境 | 优势 | 风险 |
| --- | --- | --- |
| **线下独立环境** | 可控安全 | 规格和生产不对等，数据要按规格折算且有失真风险 |
| **生产环境** | 数据最真 | 有风险，需要防护和报备 |
| **预发环境** | 接近生产 | 流量打了会影响下游 |

### 第二步：线下环境的折算问题展开

生产十六台线下两台，粗略按八分之一折算容量——但**数据库、缓存这些共享资源不随应用线性扩展**，折算只能做趋势参考。「线下压出的达标到生产翻车」是常见事故，这个风险认知要主动讲。

### 第三步：生产压测的条件展开

低峰期执行、全链路标识隔离（影子库影子表）、限流和熔断保护预埋、回滚预案、提前报备——生产压测是大厂标配但**纪律极严**，能讲出这些纪律的说明接触过正规军打法。

### 第四步：给务实选型建议

功能版本回归用线下环境够；**容量结论和大促保障必须生产或等规格环境**；预算不允许时的折中是「线下做性能问题发现，生产做容量校准」两段式。

### 收尾：讲环境一致性检查

不管哪种环境：数据量级（库里是一万条还是一个亿）、配置参数（连接池、JVM）、依赖服务版本要对齐生产——**压测结论的置信度取决于环境一致性**。这句话是本题的认知收口。

## 考察重点

| 维度 | 说明 |
| --- | --- |
| 企业动机 | 环境选择直接决定压测结论有没有效——企业要的是知道每种环境的边界、能对结论负责任的人 |
| 过线标准 | 三种环境利弊 + 线下折算的失真风险 |
| 区分度 | 讲生产压测纪律（低峰、隔离、限流、报备）的是见过大厂打法的；只说「在测试环境压」的是没做过容量级验证 |
| 加分项 | 环境一致性清单（数据量、配置、依赖版本） |
| 减分项 | 认为测试环境压过就等于生产没问题，风险意识为零 |

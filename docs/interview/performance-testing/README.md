# 性能测试面试题

> 题目整理自知识星球《面试情报 04｜性能测试 20 题》，全部来自企业面试真实出现过的题目（小林 coding 性能测试面试题库、腾讯云高并发与瓶颈分析真题、JavaGuide 性能测试专项、牛客高频题型），按面试真实展开顺序分为四组：**指标认知 → 方案执行 → 监控定位 → 专项报告**。

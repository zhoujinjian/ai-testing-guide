# 12｜效能基线和目标值怎么定？对标行业还是和自己比？

> 开场先给自己的主张：**和自己比为主、行业对标为辅**——团队的业务形态、系统复杂度、历史包袱差异巨大，行业平均值拿来当目标基本是误导（电商团队的部署频率和银行团队没有可比性）。

## 回答思路

### 第一步：基线怎么建

- **连续采集两三个迭代的稳定数据**做基线（排除异常周期，如大促月）
- 基线要**分层**：按需求类型分——大需求和小需求周期分开统计，混在一起的均值没有诊断价值
- **记录基线时的上下文**（当时的人员配置和业务背景，否则后续对比无法归因）

### 第二步：目标值怎么定才科学

- **改进幅度参考历史波动**：自然波动是正负 5%，那目标定 10% 的改进才有意义——定的比波动还小是噪声里找信号
- **分阶段爬坡**：先从四周缩到三周再到两周，不直接跳一周
- **目标由团队参与制定**：自定的目标有认同感，派下来的目标只有博弈动机

### 第三步：讲行业对标的正确用法

不是拿绝对值攀比，而是拿差距做「**可能性检验**」——DORA 报告证明有团队做到小时级前置时间，说明技术上的天花板比我们高得多，值得研究他们怎么做的。**对标用来打开视野，不是制造焦虑。**

### 收尾：讲目标之外还要看分布

**均值会骗人**——周期均值四周，可能是一半一周、一半七周的「哑铃分布」（一半需求很快一半极慢）。这个分布形态的洞察比均值有价值：**长尾那半才是改进重点**。

## 考察重点

| 维度 | 说明 |
| --- | --- |
| 企业动机 | 定错目标是效能推进失败的高频原因（目标拍脑袋、团队够不着直接躺平）——考察数据素养和管理常识的结合 |
| 过线标准 | 和自己比为主的立场 + 基线的分层和上下文 |
| 区分度 | 讲改进幅度对标自然波动、讲分布比均值有洞察的是数据专家级 |
| 加分项 | 团队参与目标制定的管理智慧 |
| 减分项 | 直接拿行业标杆值当目标压团队，不切实际且催生博弈 |

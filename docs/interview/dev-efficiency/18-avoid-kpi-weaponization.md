# 18｜怎么避免效能度量变成「考核工具」？

> 开场先讲**为什么它变成考核工具就死了**：度量一挂钩考核，行为立刻从「改进」切换到「应付」。

## 回答思路

### 第一步：死亡机制推演（理论核心）

挂钩考核 → **刷数据、藏问题、报喜不报忧** → 数据失真、改进停摆、团队抵触三连——度量体系从「改进的仪表盘」变成「**表演的舞台**」。

### 第二步：技术上的隔离设计

- 度量对象是**团队和系统**，不是个人（个人级数据不出团队，只用于自我参考）
- 效能数据和分析报告的**访问权限分级**（管理层看趋势不看个人明细）
- 指标字典里**显式声明「非考核用途」**的边界

用机制声明立场。

### 第三步：文化上的建设

- **透明共建**：指标体系怎么设计的对全员公开，讲清楚量什么、为什么量
- **度量服务团队**：团队主动用数据发现和改进自己的问题是健康态——用「**用数率**」衡量度量体系本身的健康度
- **管理层沟通**：向上有能力讲清「度量促改进」和「度量做考核」的产出差异，争取管理层对克制使用的承诺

### 第四步：讲灰色地带的处理

管理层天然想要「看人」的数据（谁效率低）——正确的应对是**引导到系统视角**（「数据看是环境等待问题，不是人的问题」，用分析结论反复校正归因习惯）。**把「问人」的问题翻译成「问系统」的问题**——这是效能团队的日常修行。

### 收尾：给平衡的边界

**不考核不等于不问责**（恶意隐瞒和长期不改进另当别论）——克制的目的是保护数据真实性和改进氛围，不是搞温情主义。分寸感讲出来才显得真理解。

## 考察重点

| 维度 | 说明 |
| --- | --- |
| 企业动机 | 效能度量「变味」是企业效能项目死亡的头号原因——管理层考核冲动和度量团队专业克制的博弈天天上演，这题是效能负责人的灵魂拷问题 |
| 过线标准 | 死亡机制推演 + 技术和文化两层的防线 |
| 区分度 | 讲「用数率」衡量度量体系健康度、讲把问人翻译成问系统的是有实战智慧的 |
| 加分项 | 不考核不等于不问责的分寸感 |
| 减分项 | 两个极端：「坚决不量人」（没有灰色地带的处理能力）或「考核才有执行力」（主动把度量做死） |

# 研发效能度量与提升面试题

> 题目整理自知识星球《面试情报 07｜研发效能度量与提升 20 题》，来自企业面试真实出现过的题目（DORA 指标与 SPACE 框架的体系问题、ONES 和思码逸整理的交付周期与缺陷逃逸率度量实践、测试之家效能度量陷阱的社区真题讨论、阿里云云效效能衡量方法的考法），按面试真实展开顺序分为四组：**认知体系 → 测试效能指标 → 度量实践 → 改进落地**。

**用法建议**：别背答案。每道题先自己口述一遍，再对照回答思路找缺口。效能度量是**测试转管理和测开转效能方向的分水岭**——这 20 题决定你能不能从「被度量的人」变成「设计度量的人」。

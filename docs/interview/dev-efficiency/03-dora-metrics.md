# 03｜DORA 四大指标是什么？怎么用？

> 开场四个指标逐一报清、各讲一句含义——DORA 是效能度量领域的**事实标准**，这题是效能方向的硬八股。

## 回答思路

### 第一步：四个指标

| 指标 | 含义 | 信号 |
| --- | --- | --- |
| **部署频率** | 多久能发布一次 | 高频小步是能力标志 |
| **变更前置时间** | 从提交代码到上线的时间 | 越短反馈越快 |
| **变更失败率** | 发布后导致故障回滚的比例 | 质量信号 |
| **服务恢复时间** | 出故障后多久恢复（MTTR） | 韧性信号 |

### 第二步：讲两两组合逻辑（DORA 的精髓）

- 部署频率 + 前置时间 → 衡量「**吞吐**」（交付流动性）
- 变更失败率 + 恢复时间 → 衡量「**稳定性**」

DORA 的洞察是：**高绩效团队两组都好（又快又稳），而不是快稳二选一**——这个「不牺牲质量的速度」的组合认知是精髓。

### 第三步：讲怎么用

1. **基线测量**：先量出团队现状落在哪个段位
2. **定位短板**：四个里哪个差补哪个——前置时间长说明流程卡点多、失败率高说明质量门禁弱
3. **改进后复测对比**

用法是「**诊断加验证**」，不是「考核排名」。

### 第四步：讲边界和本土化

DORA 度量的是**交付管道的效率**，不覆盖需求价值和人的维度（那是 SPACE 管的，04 题）——国内团队还要补缺陷逃逸率这类质量指标才完整。知道边界说明不是背概念。

### 收尾：给段位参考

精英团队**一天多次部署、前置时间小时级、失败率个位数、恢复分钟级**；传统团队一月一版、前置数周——中间差距就是改进空间。

## 考察重点

| 维度 | 说明 |
| --- | --- |
| 企业动机 | 大厂效能团队全部以 DORA 为骨架——答不出说明没系统学过度量体系 |
| 过线标准 | 四指标含义清楚 + 吞吐和稳定的组合逻辑 |
| 区分度 | 讲「诊断加验证」的用法、讲边界和本土化补充的是应用过的；只背四个名字的是刚搜过 |
| 加分项 | 精英和普通团队的段位区间数据 |
| 减分项 | 四个指标名都报不齐，硬八股不过关 |

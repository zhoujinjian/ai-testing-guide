# 测试工具平台开发面试题

> 题目整理自知识星球《面试情报 08｜测试工具平台开发 20 题》，来自企业面试真实出现过的题目（腾讯三年 78 道真题里的平台架构与技术选型、JavaGuide 测试开发面试专项、面试鸭测试架构设计考点、各社区「从 0 到 1 搭建测试平台」的高频面经），按面试真实展开顺序分为四组：**规划架构 → 核心功能设计 → 工程运营 → 综合经验**。

**用法建议**：别背答案。每道题先自己口述一遍，再对照回答思路找缺口。平台开发能力是**测开和普通测试的分界线**——这 20 题决定你能不能接到「建平台」这种级别的任务。

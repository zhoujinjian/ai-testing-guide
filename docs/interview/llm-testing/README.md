# 大模型测试面试题

> 题目整理自知识星球《面试情报 01｜大模型测试 20 题》，按面试真实展开顺序分为六组：**认知体系 → 评测集 → 指标方法 → 幻觉安全 → 性能稳定 → 工程落地**。

**用法建议**：别背答案。每道题先自己口述一遍，再对照回答思路找缺口。回答思路告诉你怎么开口、分几层展开、带什么例子；考察重点帮你读懂面试官要什么——答到点上比答得多重要。

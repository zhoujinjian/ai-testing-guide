## 按你的背景选路线

不同背景不必从第一章读到最后一章，[路线总览](./roadmap/)为三条典型路径做了定制裁剪：

| 你的背景 | 建议主线 | 参见 |
| --- | --- | --- |
| 功能 / 业务测试转测开 | 重点补编程、工程基础、接口自动化；AI 两章是你的差异化叙事 | [定制路线 A](./roadmap/#a-功能测试转测开) |
| 后端开发转测开 | 快速过基础，重点补用例设计与断言思维，发挥平台开发优势 | [定制路线 B](./roadmap/#b-后端开发转测开) |
| 校招 / 零基础 | 按顺序完整学，尽早做项目，算法不回避 | [定制路线 C](./roadmap/#c-校招零基础) |

每章末尾都有「自查清单」——能独立回答里面所有问题，这一章才算过关。跳级容易走火入魔，收藏不学则道基尽毁 😄
